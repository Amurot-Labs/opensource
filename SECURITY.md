# Security Policy

## Reporting a Vulnerability

The Amurot Open Source team takes the security and integrity of our open-source software seriously.

If you believe you have found a security vulnerability in any Amurot repository or the `oss.amurot.com` web platform, please report it to us responsibly.

### How to Report

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, please send an email to **security@amurot.com** or **bhaskar@amurot.com** with:
1. A description of the vulnerability
2. Steps to reproduce the issue
3. Any proof-of-concept code or affected components

We will acknowledge receipt of your report within 48 hours and work with you to remediate the issue promptly.
